# mileage calculator

## requirements

### input files
- must be in csv format
- state must be in two letter notation

#### origin file
- must have columns
    - `first name`
    - `last name`
    - `Street address`
    - `city`
    - `state`
    - `Zip Code`

#### destination file
- must have columns:
    - `name`
    - `Street address`
    - `city`
    - `state`
    - `Zip Code`
